# Research Workspace Instructions

These instructions apply under `research/`.

- Organize research work into numbered phase folders named `NN_short_name`.
- Start each phase with a `README.md` that states the source phase, objective,
  assumptions, commands, decision criteria, and expected next artifact.
- Keep phase documents, scripts, CSVs, plots, logs, and generated assets inside
  that phase folder. Use phase-local subdirectories such as `data/`, `figures/`,
  or `logs/` when needed.
- When a prior-phase asset becomes active work, move or copy it into the current
  phase folder and update links. Otherwise, reference prior phases read-only.
- Do not keep cache/build artifacts such as `__pycache__/` as research assets.
